## 1. 快速启动与本地预览

本项目基于 **Next.js 14 (App Router)**、**TypeScript**、**Tailwind CSS**、**Framer Motion** 与 **Lucide Icons** 构建。

```bash
# 1. 安装依赖（首次运行）
npm install

# 2. 启动开发模式（端口 3001）
npm run dev -- -p 3001

# 3. 生产模式构建与启动
npm run build
npm run start -- -p 3001
```

启动后在浏览器打开：[http://localhost:3001](http://localhost:3001) 即可体验。

## 2. 原创双 88 卡牌体系说明（88 水彩画图卡 + 88 词语卡）

本项目构建了完整的 **88 张原创水彩画风格意境图卡** 与 **88 张原创中立启发词语卡**：

- **画廊直达浏览**：可在导航栏点击 **「卡牌画廊 (88+88)」**（路由 `/cards`），直接搜索与查看全部 176 张卡牌的独立正面、大图细节与意境描述。
- **水彩美学规范**：
  - 采用水彩纸张质感（`feTurbulence` 纸纹纤维）、湿画法扩散水晕（Wet-on-wet）、通透留白与多层水痕边缘。
  - 涵盖自然风景、静物微观、生活驻足、人际隐喻等多种意境，**不设“性格诊断”标签，仅作客观画面描述**。
- **88 张原创词语卡**：
  - 涵盖状态、节律、边界、联结、转化等丰富心理投射维度（如：*距离、开始、等待、边界、选择、归属、勇气、停留、变化、允许、信任、告别、连接、空间、未知、靠近、放下、包容、寻找、声音、节奏、清晰、停顿、重量、深处、缝隙、拥抱、方向、呼吸、沉浸、温度、真实、自由、依赖、回声、秘密、平衡、渴望、破碎、重建、迷茫、笃定、隐蔽、显露、试探、承诺、孤单、共鸣、迟疑、决断、柔软、坚硬、沉淀、漂浮、痕迹、遗忘、珍藏、消耗、滋养、阻碍、通途、模糊、焦点、压抑、释放、依恋、独立、伪装、坦白、疲惫、活力、悬而未决、尘埃落定、照见、接纳、蜕变、回归、圆满* 等）。
- **纯随机解耦**：抽卡机制与用户回答严格独立，杜绝心理暗示操控。

## 3. 页面路由清单

| 页面路由 | 核心功能 |
| :--- | :--- |
| **`/` 首页** | 艺术杂志排版、主副标题、原创叠卡视觉、三步玩法引导、免责说明。 |
| **`/cards` 卡牌画廊** | **88 张水彩图卡 + 88 张词语卡**的全库检视、中英文拼音搜索、大图意境弹窗。 |
| **`/explore` 选择主题** | 5 大预设主题与最多 200 字自定义心境主题，输入与选择自由。 |
| **`/session/[id]` 抽卡与对话** | 5 选 1 翻牌、第一眼吸引点与辅助感受词记录、抽词卡并置碰撞、2~3 个中立开放追问、防抖自动保存。 |
| **`/reflection/[id]` 探索回顾** | 区分用户原话与系统整理、支持在线编辑修正、未来思考题与微小行动推荐、受控分享卡片。 |
| **`/journal` 我的探索** | 时间轴卡牌历史归档、双卡缩略图、原话摘要、单条删除与一键清空。 |
| **`/guides` 认识带领者** | 3 位真人带领者资料（严格标注“演示资料”，不虚构资质）。 |
| **`/booking/[guideId]` 预约体验** | 演示日期与时段选择、授权勾选框（默认不勾选）、提交后明确提示「流程演示完成，尚未发送预约」。 |
